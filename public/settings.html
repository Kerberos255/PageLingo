总是翻译的网址当网站为下列域名时，会自动翻译为目标语言。
永不翻译的语言当页面中某一段落的语言为下列语言时，将跳过翻译。

翻译引擎

默认使用 Firefox 本地模型；也可以添加翻译 API、LLM 或自建服务。

当前翻译引擎外部引擎会把需要翻译的文本发送给对应服务商。
Firefox 本地引擎不需要 API Key，也不会上传网页文本。外部服务的免费额度、限速和数据策略以服务商当前规则为准。
已添加引擎API Key 仅保存在 Firefox 的 browser.storage.local，不会写入项目文件或日志。
添加翻译引擎选择预设后可继续修改地址、模型和提示词。自定义 REST 只支持声明式 JSON 模板，不执行脚本。
