总是翻译的网址当网站为下列域名时，会自动翻译为目标语言。

术语库

管理品牌、技术词和项目专属术语。多个术语库可以同时启用。

术语规则“保留原文”按大小写精确匹配，适合品牌和专有名词；“指定译法”用于你明确要求的固定译法。外部 LLM 引擎会同时收到当前句子命中的术语规则。

翻译引擎

默认使用 Firefox 本地模型；也可以添加翻译 API、LLM 或自建服务。

当前翻译引擎外部引擎会把需要翻译的文本发送给对应服务商。
Firefox 本地引擎不需要 API Key，也不会上传网页文本。首次使用外部引擎时 Firefox 会请求数据传输权限；公网 Endpoint 必须使用 HTTPS，本机 localhost 可使用 HTTP。服务商的数据策略以其当前规则为准。
已添加引擎API Key 仅保存在 Firefox 的 browser.storage.local，不会写入项目文件或日志。
添加翻译引擎选择预设后可继续修改地址、模型和提示词。自定义 REST 只支持声明式 JSON 模板，不执行脚本。
