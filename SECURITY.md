# Security Policy

## Supported versions

Security fixes are provided for the latest released PageLingo version.

## Reporting a vulnerability

Please do not publish exploit details in a public issue.

Use GitHub's private vulnerability reporting / Security Advisory flow for this repository when available. If that option is unavailable, open a minimal issue asking for a private contact channel without including exploit details, secrets, private URLs, or user data.

Reports are most useful when they include the affected version, the security impact, reproduction steps, and whether the issue can expose page content, credentials, or extension privileges.
