# 复杂真实网页测试合同

本轮优先验证结构、链接与格式所指范围，再评价译文。扩展默认路径不导入本研究代码。

## 来源与抽样

公开页面列表固定在 [complex-web-v10-sites.json](external/complex-web-v10-sites.json)，覆盖 Wikipedia、Rust、TypeScript、React、Kubernetes、GitHub Docs/仓库、MDN、Python、W3C、RFC 和 Stack Overflow。无登录、无主力机浏览器或 GPU 任务。

Firefox 经环境规定代理加载真实 HTTPS 页面，导入环境公共 CA，明确 `acceptInsecureCerts=false`。使用 1440×1000 视窗；关闭图片下载与磁盘缓存，保留 DOM 图片节点、CSS 与页面脚本。因此本轮不能代表图片/视频完整加载后的视觉验证。

`collectTranslationRoots(..., {preserveInlineContext:true})` 在实际页面上采集生产候选。按源结构选取密集链接、列表/定义项、嵌套格式；补足独立表格分层。普通候选 80–900 字符、至少 12 个英文词，表格单元允许 30 字符/5 词/纯文字。规则不读取模型输出。最初采集发现缺少表格覆盖、RFC 的 `#content` 只是一节，因此在任何推理前修正抽样并保留初次证据。

每页取 3 个主样本，若尚无表格样本且页面有合格单元格则追加 1 个，共 40 个。源文本与上轮 v8 去重；它们是本轮新回归样本，不是未进入模型预训练的保证，也不是随机网页准确率样本。

## 推理与实时 DOM 验证

`tools/mt-complex-web.mjs` 从浏览器捕获的生产序列化和请求生成冻结计划。复用 `tools/mt-sentence-native.py`、实际模型、生产提示/语法/预算与 EOS 检查；以原生 CPU 顺序运行正式 v0.2.2 和旧 r16 两个 Q5，不提供参考中文、不训练或输出优化器数据。

自然目标逐字符冻结，满足源合同的样本复用 v9 INT8 对齐器；余弦 0.55、内容词完全覆盖、原节点顺序和嵌套门槛均不放宽。其余源结构、对齐或编译失败直接保留原文。

之后重新打开各真实页面，用原 CSS 定位符、完整 outerHTML、URL 和再生生产请求核对来源。来源变化就不写入并记为未测。生产分支在实际原节点上调用 PageTranslator + inferMtHtml 消费匹配的真实输出；投影分支在同一原节点上复用 captureFrozenSource/compileFrozenProjection，完成检查后立即精确恢复。

每条记录保存原节点/属性/父子顺序、祖先结构、代码内容、href 等属性及 onclick 属性身份、非导航监听器探针、恢复和局部尺寸。不会点击外部链接；探针不能枚举网站原有 addEventListener 注册，也不等同于验证目标页面导航。祖先根重叠数不等于重复文字所有权或已证实的并发错误。

这是**原生实际输出在真实 Firefox 页面上的回填测试**。未在 Firefox 中运行翻译/对齐模型，未安装并验证完整扩展引擎生命周期或 MutationObserver，不能冒称完整端到端浏览器推理测试。

## 评审

机械显示、原结构不变、格式范围与译文原意分别记分。嵌套列表等父根请求只包含其拥有的文字，子根未纳入当前请求的原文不被计为模型漏译。API 签名虽使用 dt/span/em，仍单独审核其代码性质；仅 code 标签保持不能证明所有技术内容安全。

审核逐条读取真实源、自然输出、生产输出和标签范围。没有人为编造固定槽中文正例，也没有按逐字匹配判译文。助手审查明确标注，不冒称独立人工盲审；存疑不计范围通过。拒绝保留原文计为未完成翻译。

复现入口：`tools/mt-complex-web-firefox.py` 采集/实时回填，`tools/mt-complex-web.mjs` 导出推理/冻结/回填计划，`tools/mt-complex-web-report.py` 合并完整记录与独立范围审核。源文件、页面快照、模型和运行结果都有 SHA，所有证据输出拒绝覆盖。

## 本轮生产修复与基线的区分

基线证实 Sphinx 签名会被中文化，现已在 `dom-policy` 和 PageTranslator 入口保护整个 `dt.sig` / `dt.sig-object`，包括内部链接和参数节点；相邻说明保持可翻译。正常收集、直接翻译和动态插入，以及整句/旧模式分别有回归测试。真实 Python 页面另做 4 条保护验证，全部原样保留，提供器调用为 0。

基线 152 条浏览器记录和修复后的 144 条非签名记录分列。来源匹配分别为 150 与 142，另外各 2 条被动态新增的 Wikipedia 辅助访问节点挡住。不能把未写入的来源变化当作结构通过或模型质量失败。

最初回放把 WebDriver 重排 JSON 对象字段误当成请求差异；修正仅对对象键排序，保留消息数组顺序、文本、语法与预算，再重跑。原始失败日志保留；从冻结源加这项比较修正，已逐字节重建校正后基线 runtime。两个模型的推理输出没有重跑或改写。

证据包中的 `frozen-inference-source/` 和 `corrected-baseline-source/` 用于复现修复前基线。当前源码已保护 API 签名，重新采集会选取不同的 Python 样本；用计划、源文、请求和输出 SHA 关联记录，不能只凭样本 ID 混用两轮结果。详细实测见 [v10 报告](results/2026-11-05-complex-live-web-v10.md)。
