## 翻译质量和范围检查

逐例检查覆盖全部新增 32 个源句，以及既有 29 个诊断、留出或覆盖发生变化的源句；不据此估算整站准确率。主要结果如下。

| 原句/场景 | 实际结果与判断 |
| --- | --- |
| `Unmount the volume after replacing the storage device.` | 生产提示下，旧 r16、SFT 和 DPO 均显示“卸载卷 **后** 更换存储设备。”，反转原句先后关系。格式检查未拦住。 |
| `Compress the segment before copying it to cold storage.` | SFT 显示“压缩该段数据之前，先 将其复制到冷存储。”，反转顺序；DPO 显示“压缩该段数据，**再** 将其复制到冷存储。”，这一条改善。带代码的 before 变体 DPO 仍出现“压缩 **前置** 将其复制到冷存储的片段。”，语句和关系表达不可靠。 |
| 验证 archive 后连接 peer | 生产提示的 DPO 仍仅输出“先通过 validate_peer() 成功 再 验证归档”，漏掉连接动作。研究 direct 提示恢复了验证对象，并把旧“对端必须是无效的”改为“对端无效时必须保持断开状态”，是局部改善。 |
| 通过 signal_stop() 交付 archive 后关闭传输 | DPO 生产提示仍漏掉交付动作与 archive；研究 direct 提示恢复“成功通过 signal_stop() **交付归档**，再关闭传输”。自然整句也完整，改善未稳定进入默认提示。 |
| 嵌套标题 | DPO 生产提示保持正确；研究 direct 仍显示“**不要嵌套标题**”，与肯定嵌套的英文相反。SFT 生产提示则变成缺槽拒绝。 |
| 传递任务组的已绑定 cancel() 方法 | 新增的显式 pass-bound/bind 对在两组中均能区分；但历史含“实例 **或** 已绑定方法”的研究 direct 诊断，DPO 仍将传递改为“把方法绑定到其他任务”。简单模板成绩不能推广到复杂结构。 |
| release lease before return descriptor | DPO 研究 direct 的先后关系改善，保留先归还的风险警告；但把“返回描述符回池之前完成”整段放进原本只有 `before` 的强调范围。生产提示仍有“必须在 之前将描述符返回”的残缺表达，不能视为范围与句义双通过。 |
| PolicyBinder / Thread 末尾保护项 | 模型仍会在最后一个保护项之后生成无槽动作；生产检查拒绝整段。不能靠放松解码器把越界文字显示出来。 |
| preview worker 创建和开始生成/不开始生成 | 旧 r16 的两个新验证句均格式拒绝；SFT 与 DPO 均给出完整、合法的动作与否定输出。这是此次数据训练带来的实际改善。 |
| 无修改响应、包裹签收、预订取消/退款、普通估计语气 | 已检查样本基本保持原有关系；不能将这些少量例子外推成一般可靠。统计 sink、bundles 等仍有英语残留或生硬表达。 |

自然整句诊断每组均有 3/25 个代码字面身份不符（threading 省略，两个 token 变量译为“令牌”）。自然诊断只辅助区分句义能力和固定槽输出困难，不能直接写回页面或作为发布替代路线。

冻结参考在 16 个新验证对上，训练前就已是 **16/16 chosen 的整序列 log probability 更高**；两组训练后仍都是 16/16。DPO 的相对参考平均分差从 0 到 **2.746226**，SFT 为 **0.085279**；DPO 偏好 loss 从 0.693147 到 **0.572720**。这些负例对旧模型已经偏容易，分差扩大未证明自由生成能规避错义。
