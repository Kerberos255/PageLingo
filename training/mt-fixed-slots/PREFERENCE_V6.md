# v6：格式合法的语义偏好对照与旧固定槽回放

v5 的格式接受率和参考 NLL 改善仍伴随否定、先后关系、条件和参与者错义。v6 比较相同正确目标的 SFT 与加入语义负例的 SFT+DPO。它是一次有对照的小规模研究，不代表模型已可发布；不会修改扩展默认提示、自动选赢家或上传权重。

## 数据来源与保留测试

主力机原始 v0.2/v0.2.1/v0.2.2/v0.3 和 smoke 数据使用可整体移动的旧行内标记，允许文字在标记外、保护项在标记内，不能直接作为现行固定 Text 节点协议的目标。原始 holdout/smoke-v1.1 中还有 26 条源句与某个原始训练文件相同，不能将其全体视为独立测试。原文件、最终 realweb、参考目录均不改动，也不进入本轮训练。

旧 r16 不是从原 v0.2.2 继续训练的权重；它来自固定槽 v2b 数据上的 fresh-base 训练。本轮回放使用这份**实际训练输入**，不能将两种协议混淆。旧训练文件 SHA 为 `883f8496501c31d74ae7336defdc16ab53416321c7aa5ab740d3d2d11cb9f725`；旧验证 SHA 为 `149401c637f721a54caaf6a5609cdaac1c237ba66e466ed2a997d9440549fc6d`。导出会重新生成并核对逐字节相同。

新增合成原句 96 训练、16 验证、16 留出，24/4/4 个主题家族，覆盖 before/after、肯定/否定与条件状态、传递已绑定方法/绑定方法与等待方向、代码作为工具/对象以及末尾代码前的多动作。每个家族有四个相关变体，不能当成四条独立真实网页证据。正负目标均通过生产解码器，编号和保护项序列完全相同；负例只声明某项意思被改变。助手编写及检查，**没有独立人工审核**。程序检查不证明任意语义等价。

训练和新增留出共享句式，隔离的是主题和实体，不能据此声称跨句式泛化。另加 96 条旧训练回放：60 个旧训练家族各第一条，加前 36 家族各第二条。验证回放为 16 个旧验证家族各第一条，绝不训练旧验证数据。新训练总数 192，验证总数 32；新原句与旧训练、已有评测和移除代码名后的固定槽输入均去重。已知失败集作为诊断，不声称是新的盲测。

## 两组与目标函数

两组都从同一个固定 Hy-MT2-1.8B 和旧 r16 adapter 开始，不续训被拒绝的 v3/v4/v5。先单独在 GPU 计算未更新的旧 r16 对全部 224 条输入的 chosen/rejected 目标序列 log probability，并记录输入、分词、adapter 文件与初始张量摘要。训练两组前均严格核对同一缓存和初始张量；参考不会跟随训练更新，不加载第二份常驻参考模型。

两组均使用当前生产 legacy 提示、相同正确译文、顺序和 seed；r16/alpha32、学习率 1e-5、batch 1、梯度累计 8。关闭模型与 LoRA dropout，确保参考和策略起点一致。固定 48 optimizer steps，等于 192 条输入两轮；不按验证损失挑 checkpoint。

- `sft_v6`：只优化 chosen target 的普通平均交叉熵。
- `dpo_v6`：同一 chosen CE，加 `0.25 * softplus(-0.1 * ((policy_chosen-policy_rejected) - (reference_chosen-reference_rejected)))`。DPO 使用包含标记与 EOS 的目标序列 log probability 总和；不是长度平均或内容重加权版本。回放样本只贡献 chosen CE。

prompt/padding 均屏蔽，EOS 监督，拒绝截断。两组沿用同一 chosen/rejected 前向流程，仅偏好项权重不同。beta 和权重是本轮预先固定的研究设置，尚未证明最优。序列长度偏差、合成负例的覆盖和相关主题都是实际限制；偏好似然胜出不能代替真实生成检查。

## 执行与结果

打开原 `PageLingo-MT.cmd`，执行唯一任务脚本 `x.cmd`。主力机仅做 GPU：两组实际分词与参数预检、冻结参考计分、两组训练、四组 BF16 生成和证据打包。缓存与输出留在项目盘，不需要 Firefox 或 CPU 转换，也不下载新底座。

比较底座、旧 r16、SFT 和 SFT+DPO。128 条非训练评测原句，每组 178 次、总计最多 712 次实际生成：128 次生产提示、25 次角色提示、25 次自然整句诊断，无 grammar、无草稿改写、无参考译文注入。保留 v5 评测输入，再加入 32 条新验证/留出原句；新的训练目标不作为生成评测。

结果包括固定参考缓存、初始张量摘要、训练与验证偏好指标、逐条 BF16 输出、内容/标记/EOS NLL、模型身份及证据 ZIP 的 CRC/SHA。失败会保留已保存候选与完整 traceback。COMPLETE 只表示证据齐全；云端仍需检查实际生成、生产 DOM/代码/恢复回放、语义及普通翻译回归，通过后才考虑 Q5 和 Firefox。

准备命令：先运行既有 targeted/semantic/corrective 导出，再运行 `npm run eval:mt-preference`，然后 `node tools/mt-preference-kit.mjs --out <新目录>`。正式包必须来自干净已提交源码；开发 `--allow-dirty` 和本地模型路径覆盖仅供 check，run 拒绝。原有两个可见 CMD 无需修改。
